## 16. Explain why key management is critical in symmetric encryption.**
 **Answer:** Symmetric encryption uses the same key for encryption and decryption, so the key must be securely exchanged, stored, and protected. **Poor key management can allow attackers to obtain the key and decrypt sensitive information.**

## 17. Compare stateful firewall and stateless firewall.**
 **Answer:** A stateless firewall treats each packet independently and filters it based on IP address, port, and protocol. **A stateful firewall maintains the connection state and determines whether a packet belongs to an existing connection.**

## 18. Explain how Windows Firewall protects against unauthorized access.**
 **Answer:** Windows Firewall filters incoming and outgoing network traffic according to predefined security rules. **It blocks unauthorized traffic while allowing legitimate communication and protects against malware such as worms and Trojans.**

## 19. Differentiate between active and passive attacks.**
 **Answer:** Active attacks modify data, inject malicious code, or disrupt services, affecting integrity and availability. **Passive attacks only observe or collect information without changing the system, mainly affecting confidentiality.**

## 20. Mention two uses of proxy servers in security.**
 **Answer:** A proxy server acts as an intermediary between the user and the destination, preventing a direct connection. **It can filter unwanted traffic and provide an additional layer of security between networks.**

## 21. Why is SQL injection considered dangerous?**
 **Answer:** SQL injection can allow attackers to view, modify, or delete sensitive database information. **It can also bypass authentication, escalate privileges, and potentially compromise the server.**


## 22. Explain how malware evades detection.**
 **Answer:** Malware can use obfuscation, encryption, and polymorphism to hide its malicious code from security tools. **It can also use techniques such as packet encoding and rootkits to avoid detection.**

## 23. Explain the concept of token kidnapping.**
 **Answer:** Token kidnapping is an attack in which an attacker steals an authenticated session token and uses it to impersonate the legitimate user. **The stolen token can provide unauthorized access without requiring the user's password or MFA.**

## 24. How does malware detect a virtual machine environment?**
 **Answer:** Malware can check VM-specific BIOS strings, hardware information, files, processes, and registry entries to identify virtualization. **It can also analyze system resources and other characteristics that distinguish a virtual machine from a physical system.**

## 25. State two differences between spyware and token kidnapping.**
**Answer:** Spyware is malicious software that secretly collects user information, whereas token kidnapping involves stealing an authenticated session token. **Spyware mainly targets user information and privacy, while token kidnapping allows an attacker to impersonate a legitimate user and access resources.**
