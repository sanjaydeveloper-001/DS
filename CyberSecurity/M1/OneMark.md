### Part – A: 1 Mark Answers

**1. A cipher that replaces characters with other characters is called ______.**
🟦 **Substitution Cipher**
**2. In symmetric encryption, the key must remain ______ between sender and receiver.**
🟦 **The Same**
**3. The main advantage of public key encryption is ______.**
🟦 **Secure key exchange without sharing a secret key**
**4. Microsoft Windows Security Principles are designed to enforce ______.**
🟦 **Security**
**5. A hardware firewall is ______.**
🟦 **A physical device that monitors and filters network traffic**
**6. The impact of cyber attacks on individuals includes loss of ______.**
🟦 **Privacy**
**7. The CIA triad stands for ______, ______, and ______.**
🟦 **Confidentiality, Integrity, and Availability**
**8. ______ technique encapsulates one protocol within another.**
🟦 **Tunneling**
**9. ______ is a small piece of code used to exploit vulnerabilities.**
🟦 **Exploit**
**10. A dictionary attack uses a predefined list of ______.**
🟦 **Passwords**
**11. ______ code is designed to replicate itself and spread.**
🟦 **Virus**
**12. ______ software secretly collects user information.**
🟦 **Spyware**
**13. ______ forensics is used to analyze volatile data.**
🟦 **Memory**
**14. An ______ system monitors network traffic for suspicious activity.**
🟦 **Intrusion Detection System (IDS)**
**15. ______ privilege escalation is often achieved through exploiting vulnerabilities.**
🟦 **Vertical**
